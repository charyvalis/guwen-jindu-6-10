一、或

意義（詞性）例句（出處）
有的（人），代詞
左右「或」默，「或」言馬以阿順趙高（第6課）
「或」言鹿者，高因陰中諸言鹿者以法（第6課）
有時，副詞
「或」人從之求丐者（第7課，注釋⑥）

虛字練習（課文中的虛字）

  1. 「謂鹿為馬」的「為」,意思是?
    「謂 A 為 B」= 把 A 說成是 B。
  2. 「左右或默,或言馬」的「或」,意思是?
    說的是左右的官員:有的人沉默,有的人說是馬。
  3. 「比至於外,才餘半在」的「比」,意思是?
    比(ㄅㄧˋ)= 等到;等到走到外面,只剩一半了。
  4. 「尋復囑云」的「尋」「復」,意思依序是?
    尋 = 隨即;復 = 又、再。
  5. 「於是舉州皆謂『燈』為『火』」的「舉」,意思是?
    舉州 = 整個州。舉、悉、竟都可以表示「全部」。
  6. 「揭於市曰」的「於」,意思是?
    揭於市 = 公布在市集上。對照「獻於二世」的「於」= 給。
  7. 「患記問不若人」的「若」,意思是?
    擔心記憶力比不上別人。「若」「如」可表示比較。
  8. 「或在馬上,或中夜不寢時」的「或」,意思是?
    有時在馬上,有時半夜睡不著的時候。
  9. 「古之賢君」的「之」,意思是?
    之 = 的,放在兩個名詞之間。
  10. 「立有間」的「有間」,意思是?
    有間 = 一會兒(注釋⑧:間 = 一會兒),站了一會兒。須臾、俄而、剎那、彈指也都是很短的時間。

勤學成語

  1. 下列成語,何者與「孔子讀《易經》,翻斷牛皮繩」有關?
    韋編三絕:韋是牛皮繩,編聯竹簡的繩子翻斷多次,形容讀書刻苦。
  2. 「夙夜匪懈」的「夙」「匪」,讀音依序是?
    夙(ㄙㄨˋ)= 早晨;匪(ㄈㄟˇ)= 不。
  3. 「夙夜匪懈」的「匪」,意思是?
    匪 = 不。夙夜匪懈:白天黑夜都不懈怠。
  4. 下列成語,何者與董仲舒專心讀書、不看窗外有關?
    目不窺園:專心讀書,連園子都不看。與「下帷」相呼應。
  5. 下列成語,何者「不是」形容讀書勤奮?
    朋比為奸(ㄅㄧˋ)是結黨營私,和讀書無關。
  6. 「囊螢映雪」的意思是?
    囊:用袋子裝。家中沒錢買燈油,就借螢光、雪光讀書。
  7. 「焚膏繼晷」的「晷」,意思是?
    焚膏:點燈;繼晷:接續日光。形容夜以繼日地用功。
  8. 「牛角掛書」形容什麼?
    把書掛在牛角上,趁空檔讀書。

季節與節日

  1. 「孟、仲、季」依序表示一季中的第幾個月?
    例如春季:孟春(1月)、仲春(2月)、季春(3月)。
  2. 「暮春」指的是?
    暮 = 晚、末。暮春就是季春,春天的最後一個月。
  3. 下列花木與季節的配對,何者正確?
    春:柳、桃、杏;夏:蓮、荷、瓜;秋:菊、桂、楓、茱萸;冬:雪、梅。
  4. 「獨在異鄉為異客,每逢佳節倍思親」中的「佳節」,指的是?
    詩題〈九月九日憶山東兄弟〉,9 月 9 日是重陽節,詩中還提到茱萸(秋季)。
  5. 「東風夜放花千樹……一夜魚龍舞」,描寫的是哪個節日?
    元宵節(1/15)要張掛花燈、放燈,呼應第 8 課的「上元放燈」。
  6. 「今歲今宵盡,又見一家春」,描寫的是哪個節日?
    今宵盡:今年只剩今晚,也就是除夕(12/30)。
  7. 「爆竹聲中一歲除,春風送暖入屠蘇」,描寫的是哪個節日?
    一歲除、春風送暖:舊年過去、新年開始,是元旦(1/1)。

第6課　指鹿為馬　《史記》

  1. 趙高「持鹿獻於二世」，主要的目的是什麼？
    課文說趙高「恐群臣不聽，乃先設驗」，牽鹿指為馬，是要試探群臣會不會順從他。
  2. 聽到趙高說「馬也」，二世的反應是什麼？
    「二世笑曰：丞相誤邪？謂鹿為馬。」二世以為趙高講錯了，並不知道這是試驗。
  3. 二世問左右的人，左右的反應是什麼？
    「左右或默，或言馬以阿順趙高。或言鹿者……」大臣的反應有三種。
  4. 課文最後說「後群臣皆畏高」，主要原因是什麼？
    「高因陰中諸言鹿者以法」，趙高暗中陷害說真話的人，群臣因此畏懼他。

第7課　漢世老人　《笑林》

  1. 老人平日的生活方式，最接近下列何者？
    「惡衣疏食，侵晨而起，侵夜而息，營理產業」，可見他生活儉省又勤勞。
  2. 老人取錢十文，走到門外卻只剩一半，原因是什麼？
    「自堂而出，隨步輒減」，老人每走一步就減一點，到門外只剩半數。
  3. 老人叮囑乞者「慎勿他說」，用意是什麼？
    「復相效而來」：他怕別人聽了也跟著來要錢，所以要乞者別對別人說。
  4. 這則故事主要在諷刺哪一種人？
    老人「聚斂無厭，而不敢自用」，錢財最後也只是充公，故事諷刺守財奴。

第8課　州官放火　《老學庵筆記》

  1. 課文中，觸犯田登名諱的人會有什麼下場？
    「觸者必怒，吏卒多被榜笞」，「榜笞」就是鞭打。
  2. 州內的人為什麼都把「燈」說成「火」？
    田登自諱其名，「登」與「燈」同音，眾人怕觸犯而受罰，所以改稱「火」。
  3. 官府的告示寫「本州依例，放火三日」，實際的意思是什麼？
    「火」是避諱「燈」的說法，「放火三日」其實是元宵放燈三天。
  4. 元宵節（上元）時，課文提到當時的習俗是什麼？
    「上元放燈，許人入州治遊觀。」元宵節有張掛花燈、讓人遊觀賞燈的習俗。

第9課　司馬光勤學　《三朝名臣言行錄》

  1. 司馬光幼年時擔心自己什麼？
    「患記問不若人」：擔心自己記誦、詢問的能力不如別人。
  2. 兄弟們背熟了書就去玩耍，司馬光卻怎麼做？
    「獨下帷絕編，迨能倍誦乃止」，他一個人專心苦讀，直到能背誦為止。
  3. 司馬光說「書不可不成誦」，他認為書背熟了有什麼好處？
    「或在馬上，或中夜不寢時，詠其文，思其義，所得多矣」，背熟的書隨時能拿來思考。
  4. 「用力多者收功遠」的意思，最接近下列何者？
    用力多、下功夫多的人，得到的成效長遠，所精熟背誦的內容「終身不忘」。

第10課　晏子諫君　《晏子春秋》

  1. 景公說「怪哉！雨雪三日而天不寒」，晏子的回應是什麼？
    「晏子對曰：天不寒乎？」晏子用反問委婉地提醒景公。
  2. 晏子說古代賢君的共同點是什麼？
    「飽而知人之飢，溫而知人之寒，逸而知人之勞」。
  3. 聽完晏子的話，景公實際採取的行動是什麼？
    「乃令出裘發粟與飢寒」，景公立刻發放衣服和糧食。
  4. 晏子勸諫景公的方式，最接近下列何者？
    晏子先問「天不寒乎」，再以賢君為例，說得委婉而使景公接受。

壹、虛字練習

題號答案解析
1B「謂 A 為 B」= 把 A 說成是 B。
2D說的是左右的官員:有的人沉默,有的人說是馬。
3A比(ㄅㄧˋ)= 等到;等到走到外面,只剩一半了。
4C尋 = 隨即;復 = 又、再。
5C舉州 = 整個州。舉、悉、竟都可以表示「全部」。
6A揭於市 = 公布在市集上。對照「獻於二世」的「於」= 給。
7D擔心記憶力比不上別人。「若」「如」可表示比較。
8B有時在馬上,有時半夜睡不著的時候。
9B之 = 的,放在兩個名詞之間。
10D有間 = 一會兒(注釋⑧:間 = 一會兒),站了一會兒。須臾、俄而、剎那、彈指也都是很短的時間。
11A韋編三絕:韋是牛皮繩,編聯竹簡的繩子翻斷多次,形容讀書刻苦。
12C夙(ㄙㄨˋ)= 早晨;匪(ㄈㄟˇ)= 不。
13C匪 = 不。夙夜匪懈:白天黑夜都不懈怠。
14A目不窺園:專心讀書,連園子都不看。與「下帷」相呼應。
15D朋比為奸(ㄅㄧˋ)是結黨營私,和讀書無關。
16B囊:用袋子裝。家中沒錢買燈油,就借螢光、雪光讀書。
17B焚膏:點燈;繼晷:接續日光。形容夜以繼日地用功。
18D把書掛在牛角上,趁空檔讀書。
19A例如春季:孟春(1月)、仲春(2月)、季春(3月)。
20C暮 = 晚、末。暮春就是季春,春天的最後一個月。
21C春:柳、桃、杏;夏:蓮、荷、瓜;秋:菊、桂、楓、茱萸;冬:雪、梅。
22A詩題〈九月九日憶山東兄弟〉,9 月 9 日是重陽節,詩中還提到茱萸(秋季)。
23D元宵節(1/15)要張掛花燈、放燈,呼應第 8 課的「上元放燈」。
24B今宵盡:今年只剩今晚,也就是除夕(12/30)。
25B一歲除、春風送暖:舊年過去、新年開始,是元旦(1/1)。

貳、課文選擇題（題號：課次－題號）

題號答案解析
6－1C課文說趙高「恐群臣不聽，乃先設驗」，牽鹿指為馬，是要試探群臣會不會順從他。
6－2A「二世笑曰：丞相誤邪？謂鹿為馬。」二世以為趙高講錯了，並不知道這是試驗。
6－3D「左右或默，或言馬以阿順趙高。或言鹿者……」大臣的反應有三種。
6－4B「高因陰中諸言鹿者以法」，趙高暗中陷害說真話的人，群臣因此畏懼他。
7－1B「惡衣疏食，侵晨而起，侵夜而息，營理產業」，可見他生活儉省又勤勞。
7－2D「自堂而出，隨步輒減」，老人每走一步就減一點，到門外只剩半數。
7－3A「復相效而來」：他怕別人聽了也跟著來要錢，所以要乞者別對別人說。
7－4C老人「聚斂無厭，而不敢自用」，錢財最後也只是充公，故事諷刺守財奴。
8－1C「觸者必怒，吏卒多被榜笞」，「榜笞」就是鞭打。
8－2A田登自諱其名，「登」與「燈」同音，眾人怕觸犯而受罰，所以改稱「火」。
8－3D「火」是避諱「燈」的說法，「放火三日」其實是元宵放燈三天。
8－4B「上元放燈，許人入州治遊觀。」元宵節有張掛花燈、讓人遊觀賞燈的習俗。
9－1B「患記問不若人」：擔心自己記誦、詢問的能力不如別人。
9－2D「獨下帷絕編，迨能倍誦乃止」，他一個人專心苦讀，直到能背誦為止。
9－3A「或在馬上，或中夜不寢時，詠其文，思其義，所得多矣」，背熟的書隨時能拿來思考。
9－4C用力多、下功夫多的人，得到的成效長遠，所精熟背誦的內容「終身不忘」。
10－1C「晏子對曰：天不寒乎？」晏子用反問委婉地提醒景公。
10－2A「飽而知人之飢，溫而知人之寒，逸而知人之勞」。
10－3D「乃令出裘發粟與飢寒」，景公立刻發放衣服和糧食。
10－4B晏子先問「天不寒乎」，再以賢君為例，說得委婉而使景公接受。
